Day 8: Graphs & Graph Traversal

Graph Representation, BFS, DFS, Topological Sort, Union-Find, Shortest Path

Current 📅 April 6, 2026 ⏱️ 6-8 hours

Topic Overview

Graphs are one of the most fundamental and powerful data structures in computer science. They model relationships between entities: social networks, web pages, road networks, task dependencies, and countless other real-world scenarios.

Today you'll learn graph traversal techniques (BFS and DFS), topological sorting for dependency resolution, union-find for efficient connectivity queries, and shortest path algorithms (Dijkstra, Bellman-Ford, Floyd-Warshall).

Goal: Understand when to use each graph algorithm and implement them confidently.

Pattern 1: Graph Representation

1.1 Adjacency List

The most common representation. Store neighbors for each node in a hash map or array. Space: O(V + E), Edge lookup: O(degree), Ideal for sparse graphs. 

# Adjacency List
graph = {
    0: [1, 2],
    1: [0, 2, 3],
    2: [0, 1, 3],
    3: [1, 2]
}

# Build from edges
def build_adjacency_list(edges, directed=False):
    adj = defaultdict(list)
    for u, v in edges:
        adj[u].append(v)
        if not directed:
            adj[v].append(u)
    return dict(adj)

# Time: O(E) to build, O(1) to get neighbors

1.2 Adjacency Matrix

2D array where matrix[i][j] = 1 if edge exists. Space: O(V²), Edge check: O(1). Best for dense graphs or when frequent edge existence checks are needed. 

# Adjacency Matrix (undirected)
matrix = [
    [0, 1, 1, 0],  # Node 0
    [1, 0, 1, 1],  # Node 1
    [1, 1, 0, 1],  # Node 2
    [0, 1, 1, 0]   # Node 3
]

# Check edge in O(1)
has_edge = matrix[u][v] == 1

1.3 Edge List

Simple list of (u, v, weight) tuples. Space: O(E). Used in Kruskal's MST algorithm.

Pattern 2: BFS on Graphs

2.1 BFS Traversal

Breadth-First Search visits nodes level by level using a queue. Time: O(V + E), Space: O(V). 

from collections import deque

def bfs_traversal(graph, start):
    visited = set([start])
    queue = deque([start])
    result = []

    while queue:
        node = queue.popleft()
        result.append(node)

        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    return result

# Visits nodes in order of distance from start

2.2 BFS Shortest Path

BFS naturally finds the shortest path (by number of edges) in unweighted graphs. Track the path by storing (node, path) tuples in the queue. 

def bfs_shortest_path(graph, start, end):
    if start == end:
        return [start]

    visited = set([start])
    queue = deque([(start, [start])])

    while queue:
        node, path = queue.popleft()

        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                new_path = path + [neighbor]
                if neighbor == end:
                    return new_path
                visited.add(neighbor)
                queue.append((neighbor, new_path))

    return []  # No path exists

2.3 Connected Components

Run BFS from each unvisited vertex to find all connected components. Each BFS discovers one complete component.

2.4 Bipartite Check

A graph is bipartite if it can be 2-colored (adjacent nodes have different colors). BFS with coloring: assign alternating colors level by level. 

def is_bipartite(graph, vertices):
    color = {}

    for start in vertices:
        if start in color:
            continue

        queue = deque([start])
        color[start] = 0

        while queue:
            node = queue.popleft()
            for neighbor in graph.get(node, []):
                if neighbor not in color:
                    color[neighbor] = 1 - color[node]
                    queue.append(neighbor)
                elif color[neighbor] == color[node]:
                    return False

    return True

Pattern 3: DFS on Graphs

3.1 DFS Traversal (Recursive)

Depth-First Search explores as far as possible before backtracking. Natural recursive implementation with visited set. 

def dfs_recursive(graph, start, visited=None):
    if visited is None:
        visited = set()

    visited.add(start)
    result = [start]

    for neighbor in graph.get(start, []):
        if neighbor not in visited:
            result.extend(dfs_recursive(graph, neighbor, visited))

    return result

# Time: O(V + E), Space: O(V) for recursion stack

3.2 DFS Cycle Detection (Directed)

Use 3 colors: WHITE (unvisited), GRAY (in current path), BLACK (completed). A back edge (GRAY → GRAY) indicates a cycle. 

def dfs_cycle_detection_directed(graph, vertices):
    WHITE, GRAY, BLACK = 0, 1, 2
    color = {v: WHITE for v in vertices}

    def dfs(node):
        color[node] = GRAY  # Mark as being processed

        for neighbor in graph.get(node, []):
            if color[neighbor] == GRAY:  # Back edge found
                return True
            if color[neighbor] == WHITE and dfs(neighbor):
                return True

        color[node] = BLACK  # Mark as completed
        return False

    return any(color[v] == WHITE and dfs(v) for v in vertices)

3.3 DFS Cycle Detection (Undirected)

Track parent to avoid false positive from edge back to parent. If we visit an already-visited node that isn't the parent, there's a cycle.

3.4 Find All Paths

Use backtracking to explore all possible paths from start to end. 

def dfs_find_all_paths(graph, start, end):
    all_paths = []

    def backtrack(node, path, visited):
        if node == end:
            all_paths.append(path[:])
            return

        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                path.append(neighbor)
                backtrack(neighbor, path, visited)
                path.pop()
                visited.remove(neighbor)  # Backtrack

    backtrack(start, [start], {start})
    return all_paths

Pattern 4: Topological Sort

4.1 Kahn's Algorithm (BFS-based)

Process nodes with in-degree 0, then reduce in-degrees of their neighbors. If not all nodes are processed, there's a cycle.

Applications: Course scheduling, task dependencies, build systems. 

from collections import deque

def topological_sort_kahn(graph, vertices):
    # Calculate in-degrees
    in_degree = defaultdict(int)
    for v in vertices:
        if v not in in_degree:
            in_degree[v] = 0
        for neighbor in graph.get(v, []):
            in_degree[neighbor] += 1

    # Queue of nodes with in-degree 0
    queue = deque([v for v in vertices if in_degree[v] == 0])
    result = []

    while queue:
        node = queue.popleft()
        result.append(node)

        for neighbor in graph.get(node, []):
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    if len(result) != len(vertices):
        return []  # Cycle detected

    return result

4.2 DFS-based Topological Sort

Add nodes to stack after processing all descendants (post-order), then reverse. Nodes with no outgoing edges (sinks) appear last in post-order, first when reversed. 

def topological_sort_dfs(graph, vertices):
    visited = set()
    stack = []

    def dfs(node):
        visited.add(node)
        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                dfs(neighbor)
        stack.append(node)  # Post-order

    for vertex in vertices:
        if vertex not in visited:
            dfs(vertex)

    return stack[::-1]  # Reverse for topological order

4.3 Course Schedule (LeetCode #207)

Classic application of topological sort. Can all courses be completed? Check for cycles in the prerequisite dependency graph. 

def can_finish_courses(num_courses, prerequisites):
    graph = defaultdict(list)
    in_degree = defaultdict(int)

    for course, prereq in prerequisites:
        graph[prereq].append(course)
        in_degree[course] += 1

    queue = deque([c for c in range(num_courses) if in_degree[c] == 0])
    completed = 0

    while queue:
        course = queue.popleft()
        completed += 1

        for next_course in graph[course]:
            in_degree[next_course] -= 1
            if in_degree[next_course] == 0:
                queue.append(next_course)

    return completed == num_courses

Pattern 5: Union-Find (Disjoint Set Union)

5.1 Core Operations

Union-Find maintains disjoint sets with two operations: - find(x): Find root of x (with path compression: O(α(n)) ≈ O(1)) - union(x, y): Merge sets containing x and y (by rank: O(α(n)) ≈ O(1))

Path Compression: Make all nodes point directly to root during find. Union by Rank: Attach shorter tree to taller tree to keep tree flat. 

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.num_components = n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # Path compression
        return self.parent[x]

    def union(self, x, y):
        root_x, root_y = self.find(x), self.find(y)
        if root_x == root_y:
            return False  # Already in same set

        # Union by rank
        if self.rank[root_x] < self.rank[root_y]:
            self.parent[root_x] = root_y
        elif self.rank[root_x] > self.rank[root_y]:
            self.parent[root_y] = root_x
        else:
            self.parent[root_y] = root_x
            self.rank[root_x] += 1

        self.num_components -= 1
        return True

    def connected(self, x, y):
        return self.find(x) == self.find(y)

5.2 Applications

  • Connected Components: Union all edges, count remaining components
  • Cycle Detection: If edge connects nodes already in same set, cycle exists
  • Kruskal's MST: Greedily add smallest edges that don't create cycle

5.3 Kruskal's Minimum Spanning Tree

def kruskal_mst(n, edges):
    sorted_edges = sorted(edges, key=lambda x: x[2])  # Sort by weight
    uf = UnionFind(n)
    mst = []

    for u, v, weight in sorted_edges:
        if uf.union(u, v):  # No cycle created
            mst.append((u, v, weight))
            if len(mst) == n - 1:  # MST complete
                break

    return mst

# Time: O(E log E) for sorting, Space: O(V)

Pattern 6: Shortest Path Algorithms

6.1 Dijkstra's Algorithm

Greedy algorithm using a min-heap. Always picks the closest unvisited node. Requires: Non-negative edge weights. Time: O((V + E) log V) with heap. 

import heapq

def dijkstra(graph, start):
    dist = defaultdict(lambda: float('inf'))
    dist[start] = 0
    pq = [(0, start)]  # (distance, node)

    while pq:
        d, node = heapq.heappop(pq)

        if d > dist[node]:
            continue

        for neighbor, weight in graph.get(node, []):
            new_dist = dist[node] + weight
            if new_dist < dist[neighbor]:
                dist[neighbor] = new_dist
                heapq.heappush(pq, (new_dist, neighbor))

    return dict(dist)

6.2 Bellman-Ford Algorithm

Relax all edges V-1 times. Can handle negative weights and detect negative cycles. Time: O(V · E). More versatile than Dijkstra but slower. 

def bellman_ford(n, edges, start):
    dist = defaultdict(lambda: float('inf'))
    dist[start] = 0

    # Relax all edges V-1 times
    for _ in range(n - 1):
        for u, v, weight in edges:
            if dist[u] != float('inf') and dist[u] + weight < dist[v]:
                dist[v] = dist[u] + weight

    # Check for negative cycles
    for u, v, weight in edges:
        if dist[u] != float('inf') and dist[u] + weight < dist[v]:
            return {}  # Negative cycle detected

    return dict(dist)

6.3 Floyd-Warshall Algorithm

Finds shortest paths between ALL pairs of vertices. Dynamic programming approach. Time: O(V³), Space: O(V²). Detects negative cycles. 

def floyd_warshall(n, edges):
    INF = float('inf')
    dist = [[INF] * n for _ in range(n)]

    for i in range(n):
        dist[i][i] = 0

    for u, v, weight in edges:
        dist[u][v] = weight

    # Try each vertex as intermediate
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] != INF and dist[k][j] != INF:
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])

    # Check for negative cycles
    for i in range(n):
        if dist[i][i] < 0:
            return []  # Negative cycle detected

    return dist

6.4 Algorithm Comparison

Algorithm Time Negative Weights Use Case
BFS O(V + E) N/A (unweighted) Shortest path by edge count
Dijkstra O((V+E) log V) ❌ No Single-source, non-negative
Bellman-Ford O(V · E) ✅ Yes Single-source, negative weights
Floyd-Warshall O(V³) ✅ Yes All-pairs shortest paths

Key Takeaways

  • Graphs model relationships: nodes (vertices) connected by edges
  • Adjacency list is the most common and versatile representation
  • BFS explores level by level; ideal for shortest path in unweighted graphs
  • DFS goes deep before backtracking; natural for cycle detection and path finding
  • Topological sort orders tasks with dependencies; detects cycles
  • Union-Find provides near-constant-time connectivity checks (α(n) ≈ O(1))
  • Path compression + union by rank makes Union-Find nearly optimal
  • Dijkstra is greedy with min-heap; requires non-negative weights
  • Bellman-Ford handles negative weights and detects negative cycles
  • Floyd-Warshall solves all-pairs shortest paths in O(V³)
  • Always track visited nodes to avoid infinite loops in graphs with cycles
