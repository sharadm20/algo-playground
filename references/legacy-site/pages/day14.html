1. DP Pattern Recognition Guide

The key to solving DP problems efficiently is recognizing which technique to apply.

1D DP

Look for: Linear progression, each state depends on previous 1-2 states

Examples: Fibonacci, Climbing Stairs, House Robber, Coin Change

State: dp[i] = optimal solution for first i items

Space: O(n) → O(1) with rolling variables

2D DP

Look for: Two sequences/items, grid problems, choose/not choose decisions

Examples: LCS, Edit Distance, 0/1 Knapsack, Target Sum

State: dp[i][j] = optimal solution using first i items with capacity/position j

Space: O(m*n) → O(n) with rolling array

Interval DP

Look for: Operations on ranges/subarrays, merge/split decisions, palindromes

Examples: Palindrome Partitioning, Burst Balloons, Matrix Chain Multiplication

State: dp[i][j] = optimal solution for range [i, j]

Time: O(n³) typically, iterate by length then start then split point

Tree DP

Look for: Tree structure, decisions at each node affecting children

Examples: Tree Diameter, Maximum Independent Set, Tree Coloring

State: Often returns (include_node, exclude_node) or (depth, max_value)

Space: O(h) where h is tree height (recursion stack)

Bitmask DP

Look for: Small n (≤20), subset selection, permutation tracking

Examples: TSP (Held-Karp), Assignment Problem, Subset Sum

State: dp[mask][i] = optimal value with selected items (mask), ending at i

Time: O(n² * 2^n), Space: O(n * 2^n)

Game Theory DP

Look for: Two players, optimal play, minimax decisions

Examples: Optimal Strategy Game, Coin Game, Nim Variants

State: dp[i][j] = best score/difference current player can achieve from range [i, j]

Key: Assume opponent plays optimally (minimize your gain)

Probability DP

Look for: Expected values, random processes, probability distributions

Examples: Expected Dice Rolls, Soup Servings, Random Walks

State: E[x] = 1 + Σ(E[x-transition] * probability)

Key: Use memoization for recursive expectations

2. Optimization Techniques

Technique Description Example
Space Optimization Use rolling arrays when only previous row/column needed Knapsack: O(n*W) → O(W)
State Compression Encode multiple values into single state variable Bitmask for subset tracking
1D Compression Reduce 2D DP to 1D when transitions only need previous row LCS, Edit Distance with滚动 array
Reverse Iteration Iterate backwards to avoid overwriting needed values 0/1 Knapsack inner loop

3. Problem-Solving Strategies

  1. Identify Optimal Substructure: Can the optimal solution be built from optimal subproblems?
  2. Check Overlapping Subproblems: Are the same subproblems solved multiple times?
  3. Define State Clearly: What information uniquely identifies a subproblem?
  4. Design Transitions: How do you move from one state to the next?
  5. Identify Base Cases: What are the simplest subproblems with known answers?
  6. Choose Approach: Memoization (top-down) vs Tabulation (bottom-up) based on:
    • Memoization: Only compute reachable states, easier to implement
    • Tabulation: No recursion overhead, better cache locality, easier to optimize space
  7. Optimize: Can you reduce space complexity? Eliminate redundant computations?

4. Code Examples

1D DP: House Robber (Python)

def house_robber(nums): prev2, prev1 = 0, nums[0] for i in range(1, len(nums)): curr = max(prev1, prev2 + nums[i]) prev2 = prev1 prev1 = curr return prev1

2D DP: Longest Common Subsequence (Python)

def longest_common_subsequence(text1, text2): m, n = len(text1), len(text2) dp = [[0] * (n + 1) for _ in range(m + 1)] for i in range(1, m + 1): for j in range(1, n + 1): if text1[i-1] == text2[j-1]: dp[i][j] = dp[i-1][j-1] + 1 else: dp[i][j] = max(dp[i-1][j], dp[i][j-1]) return dp[m][n]

Interval DP: Burst Balloons (Python)

def burst_balloons(nums): balloons = [1] + nums + [1] n = len(balloons) dp = [[0] * n for _ in range(n)] for length in range(2, n): for i in range(n - length): j = i + length for k in range(i + 1, j): coins = balloons[i] * balloons[k] * balloons[j] dp[i][j] = max(dp[i][j], dp[i][k] + coins + dp[k][j]) return dp[0][n - 1]

Game Theory DP: Optimal Strategy (Python)

def optimal_game_strategy(coins): n = len(coins) dp = [[0] * n for _ in range(n)] for i in range(n): dp[i][i] = coins[i] for length in range(2, n + 1): for i in range(n - length + 1): j = i + length - 1 pick_left = coins[i] + min(dp[i+2][j], dp[i+1][j-1]) pick_right = coins[j] + min(dp[i+1][j-1], dp[i][j-2]) dp[i][j] = max(pick_left, pick_right) return dp[0][n - 1]
