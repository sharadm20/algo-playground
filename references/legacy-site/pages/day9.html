🔗 1. Strongly Connected Components (SCC)

What is an SCC?

A strongly connected component is a maximal subset of vertices in a directed graph where every vertex is reachable from every other vertex in the subset.

Key Properties

  • SCCs partition the vertices of a directed graph
  • Within an SCC, all nodes can reach each other
  • Between SCCs, reachability may be one-way or non-existent
  • Condensation graph (contracting SCCs) is always a DAG

Algorithm 1: Tarjan's Algorithm

Tarjan's algorithm finds SCCs in a single DFS pass using discovery times and low-link values.

How Tarjan's Works

  1. Maintain discovery[node] - when node was first visited
  2. Maintain low_link[node] - lowest discovery time reachable
  3. Use a stack to track nodes in current DFS path
  4. When low_link[node] == discovery[node], we found an SCC root

Time: O(V + E) | Space: O(V)

Python Implementation - Tarjan's

class TarjanSCC:
    def __init__(self):
        self.timer = 0
        self.discovery = {}
        self.low_link = {}
        self.on_stack = set()
        self.stack = []
        self.sccs = []
    
    def find_sccs(self, graph):
        for node in graph:
            if node not in self.discovery:
                self._dfs(graph, node)
        return self.sccs
    
    def _dfs(self, graph, node):
        self.discovery[node] = self.timer
        self.low_link[node] = self.timer
        self.timer += 1
        self.stack.append(node)
        self.on_stack.add(node)
        
        for neighbor in graph.get(node, []):
            if neighbor not in self.discovery:
                self._dfs(graph, neighbor)
                self.low_link[node] = min(self.low_link[node], 
                                         self.low_link[neighbor])
            elif neighbor in self.on_stack:
                self.low_link[node] = min(self.low_link[node], 
                                         self.discovery[neighbor])
        
        if self.low_link[node] == self.discovery[node]:
            scc = []
            while True:
                w = self.stack.pop()
                self.on_stack.remove(w)
                scc.append(w)
                if w == node:
                    break
            self.sccs.append(scc)

Algorithm 2: Kosaraju's Algorithm

Kosaraju's uses two DFS passes: one on the original graph, one on the reversed graph.

How Kosaraju's Works

  1. DFS on original graph, push nodes to stack by finish time
  2. Reverse all edges in the graph
  3. Pop from stack and DFS on reversed graph to collect SCCs

Time: O(V + E) | Space: O(V)

💡 When to Use Which?

  • Tarjan's: Single pass, slightly faster in practice
  • Kosaraju's: Easier to understand and implement, more intuitive
  • Both are optimal - choose based on preference

🌉 2. Articulation Points & Bridges

Definitions

  • Articulation Point (Cut Vertex): A vertex whose removal disconnects the graph
  • Bridge (Cut Edge): An edge whose removal disconnects the graph

Real-World Applications

  • Network Design: Identify single points of failure
  • Infrastructure: Find critical bridges in transportation
  • Social Networks: Detect influential connectors
  • Power Grids: Ensure redundancy in electrical networks

Algorithm Overview

Uses modified DFS similar to Tarjan's SCC algorithm:

Conditions

Articulation Point:

  • Root with >1 children in DFS tree
  • Non-root node u where low_link[v] ≥ discovery[u] for child v

Bridge:

  • Edge (u, v) where low_link[v] > discovery[u]

Time: O(V + E) | Space: O(V)

Python Implementation

class ArticulationPointsAndBridges:
    def find(self, graph, num_nodes):
        self.timer = 0
        self.discovery = {}
        self.low_link = {}
        self.articulation_points = set()
        self.bridges = []
        
        for node in range(num_nodes):
            if node not in self.discovery:
                self._dfs(graph, node, parent=-1)
        
        return self.articulation_points, self.bridges
    
    def _dfs(self, graph, node, parent):
        self.discovery[node] = self.timer
        self.low_link[node] = self.timer
        self.timer += 1
        children = 0
        
        for neighbor in graph.get(node, []):
            if neighbor == parent:
                continue
            
            if neighbor in self.discovery:
                # Back edge
                self.low_link[node] = min(self.low_link[node], 
                                         self.discovery[neighbor])
            else:
                # Tree edge
                children += 1
                self._dfs(graph, neighbor, node)
                self.low_link[node] = min(self.low_link[node], 
                                         self.low_link[neighbor])
                
                # Articulation point
                if parent != -1 and self.low_link[neighbor] >= self.discovery[node]:
                    self.articulation_points.add(node)
                
                # Bridge
                if self.low_link[neighbor] > self.discovery[node]:
                    self.bridges.append((node, neighbor))
        
        # Root case
        if parent == -1 and children > 1:
            self.articulation_points.add(node)

💧 3. Network Flow (Ford-Fulkerson & Edmonds-Karp)

The Max Flow Problem

Given a network with capacities on edges, find the maximum flow from a source to a sink.

Flow Network Properties

  • Capacity Constraint: Flow ≤ Capacity for each edge
  • Flow Conservation: Flow in = Flow out (except source/sink)
  • Skew Symmetry: f(u,v) = -f(v,u)

Algorithm 1: Ford-Fulkerson

Uses DFS to find augmenting paths in the residual graph.

How It Works

  1. Build residual graph (capacity - flow)
  2. Find path from source to sink with DFS
  3. Push flow along the path (minimum bottleneck)
  4. Update residual capacities
  5. Repeat until no augmenting path exists

Time: O(f* · E) where f* is max flow value

Algorithm 2: Edmonds-Karp

Uses BFS instead of DFS to find shortest augmenting paths.

Why BFS?

  • Guarantees finding shortest augmenting path
  • Ensures algorithm terminates (unlike Ford-Fulkerson with DFS)
  • Better worst-case complexity

Time: O(V · E²)

Python Implementation - Edmonds-Karp

class EdmondsKarp:
    def max_flow(self, capacity, source, sink, nodes):
        # Build residual graph
        residual = defaultdict(lambda: defaultdict(int))
        for (u, v), cap in capacity.items():
            residual[u][v] = cap
        
        total_flow = 0
        
        while True:
            parent = {}
            flow = self._bfs_path(residual, source, sink, parent)
            
            if flow == 0:
                break
            
            # Update residual capacities
            total_flow += flow
            node = sink
            while node != source:
                prev = parent[node]
                residual[prev][node] -= flow
                residual[node][prev] += flow
                node = prev
        
        return total_flow
    
    def _bfs_path(self, residual, source, sink, parent):
        visited = {source}
        queue = deque([(source, float('inf'))])
        
        while queue:
            node, flow = queue.popleft()
            
            if node == sink:
                return flow
            
            for neighbor in residual[node]:
                if neighbor not in visited and residual[node][neighbor] > 0:
                    visited.add(neighbor)
                    parent[neighbor] = node
                    new_flow = min(flow, residual[node][neighbor])
                    queue.append((neighbor, new_flow))
                    
                    if neighbor == sink:
                        return new_flow
        
        return 0

👥 4. Bipartite Matching

Problem Statement

Given a bipartite graph (vertices split into two sets, edges only between sets), find maximum matching.

Applications

  • Job Assignment: Match workers to tasks
  • College Admissions: Match students to schools
  • Roommate Matching: Pair compatible students

Algorithm

Uses augmenting paths similar to max flow:

  1. For each left vertex, try to find augmenting path via DFS
  2. If path found, flip matching along the path
  3. Count total matches

Time: O(V · E)

class BipartiteMatching:
    def max_matching(self, graph, left_size, right_size):
        match_right = [-1] * right_size
        result = 0
        
        for u in range(left_size):
            seen = set()
            if self._dfs(graph, u, seen, match_right):
                result += 1
        
        return result
    
    def _dfs(self, graph, u, seen, match_right):
        for v in graph.get(u, []):
            if v not in seen:
                seen.add(v)
                
                if match_right[v] < 0 or \
                   self._dfs(graph, match_right[v], seen, match_right):
                    match_right[v] = u
                    return True
        
        return False

⚡ 5. Critical Connections in Networks

LeetCode 1192 - Critical Connections in a Network

Find all bridges in an undirected graph - edges whose removal disconnects the network.

💡 Solution Strategy

This is exactly the bridge-finding algorithm we covered in Section 2! The problem reduces to:

  1. Build adjacency list from connections
  2. Run DFS tracking discovery and low-link values
  3. Edge (u, v) is critical if low_link[v] > discovery[u]

Python Implementation

class CriticalConnections:
    def find_critical_connections(self, n, connections):
        graph = defaultdict(list)
        for u, v in connections:
            graph[u].append(v)
            graph[v].append(u)
        
        discovery = [-1] * n
        low_link = [-1] * n
        timer = 0
        critical = []
        
        def dfs(node, parent):
            nonlocal timer
            discovery[node] = low_link[node] = timer
            timer += 1
            
            for neighbor in graph[node]:
                if neighbor == parent:
                    continue
                
                if discovery[neighbor] == -1:
                    dfs(neighbor, node)
                    low_link[node] = min(low_link[node], low_link[neighbor])
                    
                    if low_link[neighbor] > discovery[node]:
                        critical.append([node, neighbor])
                else:
                    low_link[node] = min(low_link[node], discovery[neighbor])
        
        for i in range(n):
            if discovery[i] == -1:
                dfs(i, -1)
        
        return critical
