Day 6: Trees & Binary Trees

Binary Tree Structure, Tree Traversal, BST, Tree Properties

Current 📅 April 4, 2026 ⏱️ 4-5 hours

Topic Overview

Day 6 introduces binary trees, a hierarchical data structure where each node has at most two children. Trees are fundamental in computer science, enabling efficient searching, sorting, and organization of data. Binary Search Trees (BSTs) are particularly important, providing O(log n) operations when balanced. Understanding tree traversal and manipulation is essential for solving complex algorithmic problems.

Key Characteristics of Trees:

  • Hierarchical structure with parent-child relationships
  • Each node has at most 2 children (left and right) in binary trees
  • Root node has no parent; leaf nodes have no children
  • No cycles (unlike graphs)
  • Path from root to any node is unique
  • Height/depth measured in edges or nodes from root

Pattern 1: Tree Traversals (4 Types)

1.1 In-Order Traversal (Left → Root → Right)

In-order traversal visits the left subtree, then the root, then the right subtree. For Binary Search Trees, this produces values in sorted order—a critical property. 

def inorder_traversal(root):
    result = []
    def dfs(node):
        if node:
            dfs(node.left)
            result.append(node.val)
            dfs(node.right)
    dfs(root)
    return result

# Time: O(n), Space: O(h)

1.2 Pre-Order Traversal (Root → Left → Right)

Pre-order traversal visits the root first, then left subtree, then right subtree. Useful for creating a copy of the tree or serializing the tree structure. 

def preorder_traversal(root):
    result = []
    def dfs(node):
        if node:
            result.append(node.val)
            dfs(node.left)
            dfs(node.right)
    dfs(root)
    return result

1.3 Post-Order Traversal (Left → Right → Root)

Post-order traversal visits left subtree, then right subtree, then the root. Essential for operations that require processing children before parent.

1.4 Level-Order Traversal (BFS)

Level-order traversal visits nodes level by level, from left to right. This is a breadth-first search (BFS) approach using a queue. 

from collections import deque

def levelorder_traversal(root):
    if not root:
        return []
    result = []
    queue = deque([root])
    while queue:
        level_size = len(queue)
        current_level = []
        for _ in range(level_size):
            node = queue.popleft()
            current_level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(current_level)
    return result

Pattern 2: Binary Search Trees (BST)

A Binary Search Tree is a binary tree with a critical ordering property: for any node, all values in its left subtree are smaller, and all values in its right subtree are larger.

BST Property: left.val < root.val < right.val for all nodes

2.1 Validating a BST

To validate a BST, we must ensure all nodes in the left subtree are smaller than the root, and all nodes in the right subtree are larger. This requires passing down valid ranges. 

def is_valid_bst(root, low=-∞, high=∞):
    if not root:
        return True
    if root.val <= low or root.val >= high:
        return False
    return (is_valid_bst(root.left, low, root.val) and
            is_valid_bst(root.right, root.val, high))

# Time: O(n), Space: O(h)

2.2 BST Operations: Search, Insert, Delete

BST operations leverage the ordering property to efficiently locate the correct position. Delete requires handling three cases: leaf nodes, nodes with one child, and nodes with two children.

Pattern 3: Lowest Common Ancestor (LCA)

The Lowest Common Ancestor of two nodes p and q is the deepest node that is an ancestor of both p and q.

3.1 LCA in General Binary Tree

def lowest_common_ancestor(root, p, q):
    if not root or root == p or root == q:
        return root
    left = LCA(root.left, p, q)
    right = LCA(root.right, p, q)
    if left and right:
        return root  # p and q in different subtrees
    return left if left else right

# Time: O(n), Space: O(h)

3.2 LCA in BST (Optimized)

For BSTs, we can optimize using the BST property. Time: O(h)

Pattern 4: Tree Height and Diameter

4.1 Maximum Depth (Height)

def max_depth(root):
    if not root:
        return 0
    return 1 + max(max_depth(root.left),
                   max_depth(root.right))

# Time: O(n), Space: O(h)

4.2 Diameter of Binary Tree

The diameter is the length of the longest path between any two nodes in the tree. The key insight: the longest path through any node is left_height + right_height. 

def diameter_of_binary_tree(root):
    diameter = [0]
    def height(node):
        if not node:
            return 0
        left_h = height(node.left)
        right_h = height(node.right)
        diameter[0] = max(diameter[0], left_h + right_h)
        return 1 + max(left_h, right_h)
    height(root)
    return diameter[0]

Pattern 5: Balanced Binary Tree

A binary tree is balanced if for every node, the heights of its left and right subtrees differ by at most 1. Balanced trees guarantee O(log n) operations.

Balance Condition: |left_height - right_height| ≤ 1 for all nodes

def is_balanced(root):
    def check(node):
        if not node:
            return (True, 0)
        left_bal, left_h = check(node.left)
        right_bal, right_h = check(node.right)
        is_bal = (left_bal and right_bal and
                 abs(left_h - right_h) <= 1)
        return (is_bal, 1 + max(left_h, right_h))
    return check(root)[0]

# Time: O(n), Space: O(h)

Pattern 6: Tree Symmetry

A binary tree is symmetric if it is a mirror of itself. We check this by comparing two trees simultaneously. 

def is_symmetric(root):
    def is_mirror(t1, t2):
        if not t1 and not t2:
            return True
        if not t1 or not t2:
            return False
        return (t1.val == t2.val and
                is_mirror(t1.left, t2.right) and
                is_mirror(t1.right, t2.left))
    return is_mirror(root, root)

Pattern 7: Path Sum

Path sum problems ask whether there exists a root-to-leaf path where the sum of node values equals a target. These are solved with DFS, subtracting node values from the target sum as we traverse. 

def has_path_sum(root, target_sum):
    if not root:
        return False
    if not root.left and not root.right:
        return root.val == target_sum
    remaining = target_sum - root.val
    return (has_path_sum(root.left, remaining) or
            has_path_sum(root.right, remaining))

Key Takeaways

  • Four traversal methods: in-order, pre-order, post-order, level-order—each has specific use cases
  • In-order traversal of BST yields sorted values
  • BST validation requires passing ranges, not just checking local property
  • Tree height and diameter can be computed simultaneously in O(n)
  • Balance condition: |left_height - right_height| ≤ 1
  • LCA in general tree: O(n) with post-order; in BST: O(h) using BST property
  • Path sum problems use DFS with target subtraction
  • Recursive solutions are elegant; iterative solutions use stacks/queues
