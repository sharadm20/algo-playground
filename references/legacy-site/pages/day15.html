Day 15: Heaps, Tries, & Bit Manipulation

Date: April 13, 2026

Focus: Priority queues, prefix trees, and bitwise operations

Overview

Today we cover three powerful data structures and techniques: Heaps (Priority Queues) for efficient extremum retrieval, Tries for prefix-based string operations, and Bit Manipulation for space-efficient computations. These patterns are essential for competitive programming and technical interviews.

1. Heaps & Priority Queues

1.1 Conceptual Foundation

A heap is a specialized tree-based data structure that satisfies the heap property. In a min-heap, for any node i, the value of i is less than or equal to its children's values. In a max-heap, the opposite holds. Heaps are commonly used to implement priority queues.

Key Properties:

  • Complete binary tree (filled left to right)
  • Min-heap: parent ≤ children; Max-heap: parent ≥ children
  • Array representation: children of index i are at 2i+1 and 2i+2
  • Root is always the minimum (min-heap) or maximum (max-heap)

1.2 Time Complexities

Operation Time Complexity Space Complexity
Push/Insert O(log n) O(n)
Pop/Extract O(log n) O(1)
Peek/Top O(1) O(1)
Heapify O(n) O(1)

1.3 Common Patterns

Pattern 1: Top K Frequent Elements

Problem: Given an array, find the k most frequent elements.

Approach: Use a min-heap of size k to track the top k elements while iterating through frequencies. When heap size exceeds k, remove the minimum (least frequent).

Time: O(n log k) instead of O(n log n) for full sorting

Pattern 2: Merge K Sorted Lists

Problem: Merge k sorted linked lists into one sorted list.

Approach: Use a min-heap of size k, initially containing the first element of each list. Extract minimum and insert next element from the same list.

Time: O(n log k) where n is total elements and k is number of lists

Pattern 3: Find Median from Data Stream

Problem: Design a data structure that supports addNum and findMedian.

Approach: Maintain two heaps: a max-heap for the lower half and a min-heap for the upper half. Balance sizes to ensure efficient median retrieval.

Time: O(log n) insert, O(1) find median

2. Trie (Prefix Tree)

2.1 Conceptual Foundation

A trie, also called a prefix tree, is a tree-like data structure used to store a dynamic set of strings. Each node represents a character, and paths from root to nodes represent prefixes. Tries are particularly efficient for string operations like autocomplete, spell checking, and IP routing.

Key Properties:

  • Root represents empty string
  • Each edge represents a character
  • Nodes may have multiple children (one per character)
  • Special marker indicates end of word
  • Common prefixes share the same path

2.2 Time Complexities

Operation Time Complexity Space Complexity
Insert O(m) O(m × n)
Search O(m) O(1)
StartsWith O(m) O(1)

Where m = word length, n = number of words

2.3 Common Patterns

Pattern 1: Autocomplete System

Use trie to store dictionary words. For autocomplete, traverse to the prefix node, then perform DFS to collect all words with that prefix. Combine with frequency tracking for ranking suggestions.

Pattern 2: Word Search on Board

Given a 2D board and a list of words, find all words that can be formed. Build trie from word list, then DFS from each cell, following trie edges. Mark visited cells to avoid reuse.

Pattern 3: Longest Common Prefix

Insert all strings into trie, then traverse from root following the path where all strings share characters. Stop at first branching point or word end.

3. Bit Manipulation

3.1 Conceptual Foundation

Bit manipulation involves working directly with binary representations of integers. Understanding bitwise operations enables efficient solutions to problems involving sets, subsets, and mathematical properties. Many bit manipulation solutions achieve O(1) space and O(n) time complexity.

Basic Operations:

  • AND (&): 1 if both bits are 1
  • OR (|): 1 if at least one bit is 1
  • XOR (^): 1 if bits are different (commutative, associative)
  • NOT (~): Flips all bits
  • Left Shift (<<): Multiply by 2
  • Right Shift (>>): Divide by 2

3.2 Key Bit Manipulation Tricks

1. Check if power of 2: n > 0 and (n & (n - 1)) == 0
2. Get bit at position i: (n >> i) & 1
3. Set bit at position i: n | (1 << i)
4. Clear bit at position i: n & ~(1 << i)
5. Toggle bit at position i: n ^ (1 << i)
6. XOR of same number is 0: n ^ n = 0
7. XOR with 0 is identity: n ^ 0 = n
8. Count set bits: n & (n - 1) clears lowest set bit
9. Swap without temp: a ^= b; b ^= a; a ^= b
10. Get lowest set bit: n & (-n)

3.3 Common Patterns

Pattern 1: Single Number (XOR)

Problem: Given array where every element appears twice except one, find the single element.

Approach: XOR all elements: duplicates cancel out, leaving only the unique element.

Time: O(n), Space: O(1)

Pattern 2: Counting Bits

Problem: For each number from 0 to n, count the number of 1-bits.

Approach: Use dynamic programming: bits[i] = bits[i >> 1] + (i & 1) or bits[i] = bits[i & (i-1)] + 1

Time: O(n), Space: O(n)

Pattern 3: Subsets with Bitmask

Problem: Generate all subsets of a set.

Approach: Use integers from 0 to 2^n - 1 as bitmasks, where bit i indicates whether element i is in the subset.

Time: O(2^n), Space: O(1) auxiliary

4. Practice Problems

4.1 Heap Problems

  • Top K Frequent Elements: Use min-heap of size k to track most frequent
  • Kth Largest Element in Array: Use min-heap or quickselect
  • Merge K Sorted Lists: Use min-heap to merge efficiently
  • Find Median from Data Stream: Use two heaps (max-heap and min-heap)
  • Sliding Window Maximum: Use deque or heap with lazy removal

4.2 Trie Problems

  • Implement Trie: Insert, search, and prefix operations
  • Word Search II: Find all words from dictionary on board
  • Longest Word in Dictionary: Find longest buildable word
  • Map Sum Pairs: Trie with value aggregation
  • Design Add and Search Words: Wildcard search with trie

4.3 Bit Manipulation Problems

  • Single Number: XOR all elements to find unique
  • Number of 1 Bits: Count set bits (Hamming weight)
  • Counting Bits: DP with bit manipulation
  • Reverse Bits: Bit reversal with shifts
  • Power of Two: Check with n & (n-1)
  • Sum of Two Integers: Addition using only XOR and AND

5. Key Takeaways

  1. Heaps provide O(log n) insertion and extraction of min/max, ideal for priority-based processing
  2. Top K problems benefit from heaps of size k instead of full sorting
  3. Two heaps (max-heap + min-heap) efficiently solve median-finding and range problems
  4. Tries excel at prefix operations and string set membership queries
  5. Bit manipulation enables O(1) space solutions for subset and uniqueness problems
  6. XOR properties (n ^ n = 0, n ^ 0 = n) are powerful for cancellation-based solutions
  7. Bitmasks represent subsets compactly when n is small (n ≤ 20-25)
  8. Understanding time/space tradeoffs is crucial: heaps for streaming, tries for prefix queries, bits for compactness
