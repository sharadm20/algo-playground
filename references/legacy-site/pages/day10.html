1. Pattern Recognition Guide

The key to solving DSA problems efficiently is recognizing which pattern or technique to apply.

Hash Maps/Sets

Look for: Finding pairs, checking membership, counting frequency, eliminating duplicates

Examples: Two Sum, Group Anagrams, Contains Duplicate, Valid Anagram

Time: O(n) average, Space: O(n)

Two Pointers

Look for: Sorted array, finding pairs, palindrome check, subarray problems

Examples: Two Sum II, 3Sum, Container With Most Water, Valid Palindrome

Time: O(n), Space: O(1)

Sliding Window

Look for: Contiguous subarray/substring, longest/shortest substring, fixed-size window

Examples: Longest Substring Without Repeating, Minimum Window Substring

Time: O(n), Space: O(k) where k is window size

Stack

Look for: Parentheses matching, next greater element, expression evaluation

Examples: Valid Parentheses, Daily Temperatures, Eval RPN

Time: O(n), Space: O(n)

BFS/DFS

Look for: Tree traversal, level-order, shortest path, connected components

Examples: Number of Islands, Rotting Oranges, Word Ladder

BFS: Shortest path in unweighted graphs, O(V + E) time

DFS: Path existence, cycle detection, O(V + E) time

Union-Find

Look for: Connected components, cycle detection, dynamic connectivity

Examples: Number of Connected Components, Redundant Connection

Time: O(α(n)) ≈ O(1) per operation

Dijkstra

Look for: Shortest path in weighted graph, non-negative edge weights

Examples: Network Delay Time, Path With Minimum Effort

Time: O((V + E) * log(V)) with priority queue

2. Complexity Analysis Techniques

Proving Time Complexity

  1. Count the number of operations relative to input size n
  2. Identify loops, recursive calls, and nested structures
  3. Use the Master Theorem for divide-and-conquer recurrences
  4. Remember common patterns:
    • Single loop: O(n)
    • Nested loops: O(n²) or O(n * m)
    • Halving each time: O(log n)
    • Divide and conquer: O(n log n)
    • All permutations/subsets: O(2^n) or O(n!)

Proving Space Complexity

  1. Count extra space used (excluding input)
  2. Consider:
    • Hash maps/sets: O(n)
    • Recursion stack: O(h) where h is tree/graph height
    • Auxiliary arrays: O(n) or O(n * m)
  3. In-place algorithms: O(1) extra space

3. Problem Decomposition Strategies

Breaking complex problems into subproblems:

  1. Identify the core operation (what are we trying to find?)
  2. Identify constraints (time limit, memory limit, input size)
  3. Break into phases:
    • Preprocessing: Sort, build hash map, build graph
    • Main computation: Apply algorithm pattern
    • Post-processing: Format output, handle edge cases
  4. Solve each subproblem independently
  5. Combine solutions

4. Code Examples

Two Sum (Python)

def two_sum(nums, target): seen = {} for i, num in enumerate(nums): complement = target - num if complement in seen: return [seen[complement], i] seen[num] = i return []

Dijkstra's Algorithm (Python)

import heapq def dijkstra(graph, start): distances = {node: float('inf') for node in graph} distances[start] = 0 pq = [(0, start)] while pq: curr_dist, curr_node = heapq.heappop(pq) if curr_dist > distances[curr_node]: continue for neighbor, weight in graph[curr_node]: distance = curr_dist + weight if distance < distances[neighbor]: distances[neighbor] = distance heapq.heappush(pq, (distance, neighbor)) return distances
