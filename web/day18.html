Day 18: Segment Trees & Binary Indexed Trees

Overview

Segment Trees and Binary Indexed Trees (Fenwick Trees) are advanced data structures used for efficient range queries and point updates on arrays. These structures are essential for solving problems involving range sums, range minima/maxima, and other range-based operations in logarithmic time.

Segment Trees

Introduction

A segment tree is a binary tree data structure that allows range queries and point updates in O(log n) time. It is particularly useful for problems requiring efficient range queries and updates.

Structure

  • Leaf Nodes: Represent individual elements of the array.
  • Internal Nodes: Represent ranges of the array and store aggregated information (e.g., sum, minimum, maximum) for those ranges.

Operations

  1. Construction: Build the segment tree from an array.
  2. Query: Retrieve aggregated information for a range [l, r].
  3. Update: Update the value at a specific index and propagate the change up the tree.

Applications

  • Range Sum Queries (RSQ)
  • Range Minimum/Maximum Queries (RMQ)
  • Range Updates with Lazy Propagation

Python Implementation

class SegmentTree:
    def __init__(self, data):
        self.n = len(data)
        self.size = 1
        while self.size < self.n:
            self.size <<= 1
        self.tree = [0] * (2 * self.size)
        
        # Build the tree
        for i in range(self.n):
            self.tree[self.size + i] = data[i]
        for i in range(self.size - 1, 0, -1):
            self.tree[i] = self.tree[2 * i] + self.tree[2 * i + 1]
    
    def update(self, index, value):
        index += self.size
        self.tree[index] = value
        index >>= 1
        while index >= 1:
            new_val = self.tree[2 * index] + self.tree[2 * index + 1]
            if self.tree[index] == new_val:
                break
            self.tree[index] = new_val
            index >>= 1
    
    def query_range(self, l, r):
        res = 0
        l += self.size
        r += self.size
        while l <= r:
            if l % 2 == 1:
                res += self.tree[l]
                l += 1
            if r % 2 == 0:
                res += self.tree[r]
                r -= 1
            l >>= 1
            r >>= 1
        return res

Rust Implementation

pub struct SegmentTree {
    n: usize,
    size: usize,
    tree: Vec,
}

impl SegmentTree {
    pub fn new(data: &[i32]) -> Self {
        let n = data.len();
        let mut size = 1;
        while size < n {
            size <<= 1;
        }
        
        let mut tree = vec![0; 2 * size];
        
        // Build the tree
        for i in 0..n {
            tree[size + i] = data[i];
        }
        for i in (1..size).rev() {
            tree[i] = tree[2 * i] + tree[2 * i + 1];
        }
        
        SegmentTree { n, size, tree }
    }
    
    pub fn update(&mut self, index: usize, value: i32) {
        let mut pos = self.size + index;
        self.tree[pos] = value;
        let mut pos = pos / 2;
        
        while pos >= 1 {
            let new_val = self.tree[2 * pos] + self.tree[2 * pos + 1];
            if self.tree[pos] == new_val {
                break;
            }
            self.tree[pos] = new_val;
            pos /= 2;
        }
    }
    
    pub fn query_range(&self, l: usize, r: usize) -> i32 {
        let mut res = 0;
        let mut l = self.size + l;
        let mut r = self.size + r;
        
        while l <= r {
            if l % 2 == 1 {
                res += self.tree[l];
                l += 1;
            }
            if r % 2 == 0 {
                res += self.tree[r];
                r -= 1;
            }
            l /= 2;
            r /= 2;
        }
        
        res
    }
}

Binary Indexed Trees (Fenwick Trees)

Introduction

A Binary Indexed Tree (BIT) is a data structure that provides efficient methods for calculating prefix sums and updating elements in an array. It is more space-efficient than segment trees but supports fewer operations.

Structure

  • Tree Representation: Uses an array-based representation where each node stores the sum of a specific range of elements.
  • Indexing: Uses bit manipulation to navigate the tree structure.

Operations

  1. Update: Add a value to an element and propagate the change to affected nodes.
  2. Query: Calculate the prefix sum up to a specific index.

Applications

  • Prefix Sum Queries
  • Point Updates
  • Inversion Counting

Python Implementation

class FenwickTree:
    def __init__(self, size):
        self.size = size
        self.tree = [0] * (self.size + 1)
    
    def update(self, index, delta):
        while index <= self.size:
            self.tree[index] += delta
            index += index & -index
    
    def query(self, index):
        res = 0
        while index > 0:
            res += self.tree[index]
            index -= index & -index
        return res

Rust Implementation

pub struct FenwickTree {
    size: usize,
    tree: Vec,
}

impl FenwickTree {
    pub fn new(size: usize) -> Self {
        FenwickTree {
            size,
            tree: vec![0; size + 1],
        }
    }
    
    pub fn update(&mut self, mut index: usize, delta: i32) {
        while index <= self.size {
            self.tree[index] += delta;
            index += index & !index + 1;
        }
    }
    
    pub fn query(&self, mut index: usize) -> i32 {
        let mut res = 0;
        while index > 0 {
            res += self.tree[index];
            index -= index & !index + 1;
        }
        res
    }
}

Problems and Solutions

Problem 1: Range Sum Query

Given an array of integers, implement a data structure to answer range sum queries efficiently.

Solution: Use a segment tree to support range sum queries and point updates in O(log n) time.

Problem 2: Inversion Count

Given an array of integers, count the number of inversions (pairs (i, j) where i < j and arr[i] > arr[j]).

Solution: Use a Binary Indexed Tree to count inversions efficiently.

Problem 3: Range Minimum Query

Given an array of integers, implement a data structure to answer range minimum queries efficiently.

Solution: Use a segment tree to support range minimum queries and point updates in O(log n) time.
