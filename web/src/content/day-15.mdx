## Overview

**Heaps** and **Tries** are specialised tree structures that solve very different problems. A heap (priority queue) gives O(log n) insertion and O(log n) extraction of the min or max element — invaluable for anytime you need to repeatedly access the largest or smallest item in a dynamic set. A trie (prefix tree) gives O(k) prefix lookups over a set of strings, where k is the key length, regardless of how many strings are stored.

Both structures are frequently used as building blocks in more complex algorithms (heap for Dijkstra's, median finding; trie for autocomplete, IP routing, spell checkers).

## Key Concepts

- **Min-Heap vs Max-Heap**: In a min-heap the parent is always ≤ its children; in a max-heap the parent is always ≥ its children. Python's `heapq` implements a min-heap; use negative values for max-heap behavior.
- **Heap Operations**: `push` (append then sift up), `pop` (swap with last, sift down), `heapify` (build heap in O(n) from an array).
- **Trie Structure**: Each node stores a map of child characters and a boolean flag indicating whether a word ends here. Insertion and search both walk character by character.
- **Space vs Speed**: Tries trade memory for speed — they can be memory-heavy but offer O(key_length) lookups with no hash collisions.

def find_kth_largest(nums: list[int], k: int) -> int:
    heap = nums[:k]

class Trie:
    class Node:
        def __init__(self):
            self.children: dict[str, "Trie.Node"] = {}
            self.is_end = False

    def __init__(self):
        self.root = self.Node()

    def insert(self, word: str) -> None:
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = self.Node()
            node = node.children[ch]
        node.is_end = True

    def search(self, word: str) -> bool:
        node = self.root
        for ch in word:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return node.is_end

        node = self.root
        for ch in prefix:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return True

## Key Takeaways

<InsightBox title="Key Insights">
- Python's `heapq` is a min-heap. To simulate a max-heap, push negative values: `heapq.heappush(h, -x)`.
- The "top K" pattern is the most common heap interview question — maintain a size-k min-heap for k largest, a size-k max-heap for k smallest.
- Tries shine when you need prefix-based operations. They outperform hash tables for "words starting with..." queries.
- The two-heap pattern (one min-heap, one max-heap, balanced in size) elegantly solves median-finding and sliding-window median problems.
</InsightBox>
