## Overview

Today is a comprehensive review of everything covered in Week 1: arrays, hash maps, strings, stacks, queues, linked lists, and trees. The goal is to solve mixed-topic problems that force you to combine techniques from multiple days. Review days are where the learning solidifies — you move from "I've seen this pattern" to "I can recognize the right pattern instantly."

As you work through these problems, think about which data structure or technique each one needs. Is it a hash map problem? A two-pointer problem? A recursive tree traversal? Being able to categorise a problem within seconds is the skill that separates strong candidates from weak ones.

## Multi-Language Comparison

Seeing the same algorithm in different languages reveals what each language optimizes for. Here's a linked list reversal in Python, JavaScript, and Rust:

<CodePlayground language="python" initialCode={`# Python — clear and concise
def reverse(head):
    prev, curr = None, head
    while curr:
        curr.next, prev, curr = prev, curr, curr.next
    return prev
`} />

<CodePlayground language="javascript" initialCode={`// JavaScript — same logic, explicit temp variable
function reverse(head) {
    let prev = null, curr = head;
    while (curr) {
        const next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
`} />

<CodePlayground language="rust" initialCode={`// Rust — ownership forces thinking about borrowing
fn reverse(head: Option<Box<ListNode>>) -> Option<Box<ListNode>> {
    let mut prev = None;
    let mut curr = head;
    while let Some(mut node) = curr {
        curr = node.next.take();
        node.next = prev;
        prev = Some(node);
    }
    prev
}
`} />

## Practice Problems

<ProblemCard title="Group Anagrams" difficulty="medium" pattern="Hash Map + String">
  Given an array of strings `strs`, group the anagrams together. Each group should contain strings that are anagrams of each other.

  **Example:** `strs = ["eat", "tea", "tan", "ate", "nat", "bat"]` → `[["bat"], ["nat", "tan"], ["ate", "eat", "tea"]]`
</ProblemCard>

<ProblemCard title="Binary Tree Inorder Traversal (Iterative)" difficulty="medium" pattern="Stack + Tree">
  Given the `root` of a binary tree, return the inorder traversal of its nodes' values iteratively (without recursion).

  **Example:** `root = [1, null, 2, 3]` → `[1, 3, 2]`
</ProblemCard>

<ProblemCard title="Intersection of Two Linked Lists" difficulty="easy" pattern="Two Pointers / Hash Set">
  Given the heads of two singly linked lists, return the node at which they intersect. If no intersection exists, return `null`.

  **Example:** `listA = [4, 1, 8, 4, 5]`, `listB = [5, 6, 1, 8, 4, 5]` → intersection at node with value `8`
</ProblemCard>
