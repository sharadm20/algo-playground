## Overview

You've now encountered DFS, BFS, binary search, and trie-based searching — each with different strengths. Today we consolidate by comparing search strategies head-to-head and applying them across different data structures. Knowing *which* search to use is as important as knowing *how* to implement it.

The choice between DFS and BFS often comes down to whether you need the shortest path (BFS on unweighted graphs) or whether you want to explore deeply first (DFS for topological sort, cycle detection, backtracking). Binary search is a completely different category: it exploits order rather than adjacency.

## Code Example

<CodePlayground language="python" initialCode={`from collections import deque


def dfs(graph: dict[int, list[int]], start: int, visited: set[int] | None = None) -> list[int]:
    if visited is None:
        visited = set()
    result: list[int] = []
    visited.add(start)
    result.append(start)
    for neighbor in graph.get(start, []):
        if neighbor not in visited:
            result.extend(dfs(graph, neighbor, visited))
    return result


def bfs(graph: dict[int, list[int]], start: int) -> list[int]:
    visited = {start}
    q = deque([start])
    result = []
    while q:
        node = q.popleft()
        result.append(node)
        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                q.append(neighbor)
    return result


graph = {0: [1, 2], 1: [0, 3], 2: [0, 3], 3: [1, 2]}
print(dfs(graph, 0))  # [0, 1, 3, 2]
print(bfs(graph, 0))  # [0, 1, 2, 3]
`} />

<CodePlayground language="javascript" initialCode={`// Graph search in JavaScript
function dfs(graph, start, visited = new Set()) {
  visited.add(start);
  const result = [start];
  for (const neighbor of graph[start] || []) {
    if (!visited.has(neighbor)) {
      result.push(...dfs(graph, neighbor, visited));
    }
  }
  return result;
}

function bfs(graph, start) {
  const visited = new Set([start]);
  const queue = [start];
  const result = [];
  while (queue.length) {
    const node = queue.shift();
    result.push(node);
    for (const neighbor of graph[node] || []) {
      if (!visited.has(neighbor)) {
        visited.add(neighbor);
        queue.push(neighbor);
      }
    }
  }
  return result;
}

const graph = { 0: [1, 2], 1: [0, 3], 2: [0, 3], 3: [1, 2] };
console.log(dfs(graph, 0)); // [0, 1, 3, 2]
console.log(bfs(graph, 0)); // [0, 1, 2, 3]
`} />

## Key Takeaways

<InsightBox title="Key Insights">
- Use BFS when the shortest path in an unweighted graph matters. Use DFS when you need to visit every node or detect cycles.
- Binary search is not just for arrays — any monotonic predicate space can be binary-searched. The hard part is writing the predicate, not the search itself.
- Graph search problems on grids are isomorphic to graph search problems on adjacency lists — the same algorithms apply with different neighbor generation.
- In interviews, be explicit about which search strategy you're using and why. The reasoning matters more than the code.
</InsightBox>
