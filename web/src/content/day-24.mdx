## Overview

Topological sort returns a linear ordering of vertices in a directed acyclic graph (DAG) such that for every directed edge u → v, u comes before v. It is the algorithmic foundation of dependency resolution — build systems (Make, Bazel), package managers (npm, pip), and course prerequisite planners all rely on topological ordering.

Two main algorithms exist: **Kahn's algorithm** (BFS-based, uses in-degree counts) and **DFS-based topological sort** (uses finish times / stack ordering). Kahn's algorithm has the bonus of built-in cycle detection — if not all vertices are processed, a cycle exists.

## Key Concepts

- **DAG**: A directed acyclic graph — cycles make topological ordering impossible.
- **Kahn's Algorithm**: Repeatedly remove vertices with in-degree 0, adding them to the order. Decrease neighbors' in-degrees.
- **DFS-based Algorithm**: Run DFS; add a vertex to the front of the result list after visiting all its neighbors (post-order).
- **Cycle Detection**: If Kahn's algorithm finishes without processing all vertices, a cycle exists.

## Code Example

<CodePlayground language="python" initialCode={`from collections import defaultdict, deque


def kahn_topological_sort(num_nodes, edges):
    """
    Kahn's algorithm: BFS-based topological sort.

    edges: list of (u, v) meaning u -> v
    Returns: topological ordering, or empty list if cycle exists
    """
    graph = defaultdict(list)
    in_degree = [0] * num_nodes

    for u, v in edges:
        graph[u].append(v)
        in_degree[v] += 1

    queue = deque([i for i in range(num_nodes) if in_degree[i] == 0])
    result = []

    while queue:
        node = queue.popleft()
        result.append(node)
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    return result if len(result) == num_nodes else []


def dfs_topological_sort(num_nodes, edges):
    """DFS-based topological sort using post-order traversal."""
    graph = defaultdict(list)
    for u, v in edges:
        graph[u].append(v)

    visited = [False] * num_nodes
    stack = []

    def dfs(node):
        visited[node] = True
        for neighbor in graph[node]:
            if not visited[neighbor]:
                dfs(neighbor)
        stack.append(node)  # post-order

    for i in range(num_nodes):
        if not visited[i]:
            dfs(i)

    return stack[::-1]  # reverse post-order


# Example: 6 nodes, edges 0->1, 0->2, 1->3, 2->3, 3->4, 4->5
edges = [(0, 1), (0, 2), (1, 3), (2, 3), (3, 4), (4, 5)]
print("Kahn:", kahn_topological_sort(6, edges))
print("DFS:", dfs_topological_sort(6, edges))

## Key Takeaways

<InsightBox title="Key Insights">
- Topological sort only works on DAGs — cycle detection is a critical part of the algorithm.
- Kahn's algorithm (BFS) is generally easier to implement and has natural cycle detection.
- DFS-based topological sort produces the reverse of a post-order traversal.
- Real-world applications: build systems, course planners, dependency resolution, and Alien Dictionary (a classic interview problem).
</InsightBox>
