## Overview

Trees are the most important non-linear data structure. A binary tree is a recursive structure where each node has at most two children (left and right). A Binary Search Tree (BST) adds the invariant: all left descendants < node value < all right descendants. This property enables O(log n) search in a balanced tree.

Tree traversals define the order in which nodes are visited. Inorder traversal of a BST yields sorted order. Preorder creates a copy. Postorder deletes children before parents. Level-order (BFS) visits by depth. Most tree problems reduce to choosing the right traversal and adding logic at the right point.

## Key Concepts

- **Binary Tree**: Each node has `val`, `left`, `right` pointers. Recursive by nature — every subtree is itself a tree.
- **BST Invariant**: Left subtree values < root < right subtree values. This enables binary search.
- **DFS Traversals**: Inorder (left, root, right), Preorder (root, left, right), Postorder (left, right, root).
- **BFS / Level-Order**: Use a queue to visit nodes level by level. Useful for shortest path, right-side view.

## Code Example

<CodePlayground language="python" initialCode={`class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def max_depth(root):
    if not root:
        return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))

def build_tree(vals, i=0):
    if i >= len(vals) or vals[i] is None:
        return None
    node = TreeNode(vals[i])
    node.left = build_tree(vals, 2 * i + 1)
    node.right = build_tree(vals, 2 * i + 2)
    return node

root = build_tree([3, 9, 20, None, None, 15, 7])
print(max_depth(root))  # 3
`} />
