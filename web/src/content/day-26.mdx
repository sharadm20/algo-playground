## Overview

A Minimum Spanning Tree (MST) of a weighted, undirected graph is a subset of edges that connects all vertices with the minimum possible total edge weight and no cycles. MSTs are fundamental in network design — laying cables, building roads, designing circuit boards, and clustering (single-linkage clustering is essentially Kruskal's algorithm).

Two classic algorithms dominate: **Kruskal's** (sort edges by weight, greedily add safe edges using Union-Find) and **Prim's** (grow a tree from a starting vertex using a min-heap). Both are greedy and both yield optimal MSTs, but their performance characteristics differ based on graph density.

## Key Concepts

- **Cut Property**: For any cut, the minimum-weight edge crossing the cut belongs to some MST — this is what proves both Kruskal's and Prim's correct.
- **Kruskal's Algorithm**: Sort all edges O(E log E), iterate and union if no cycle. Best for sparse graphs.
- **Prim's Algorithm**: Grow from a seed vertex using a min-priority queue. Best for dense graphs.
- **Time Complexity**: Kruskal is O(E log V) with sorting; Prim is O(E log V) with binary heap, O(V²) with adjacency matrix on dense graphs.

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            self.parent[px] = py
        elif self.rank[px] > self.rank[py]:
            self.parent[py] = px
        else:
            self.parent[py] = px
            self.rank[px] += 1
        return True


def kruskal_mst(n, edges):
    """
    edges: list of (weight, u, v)
    Returns: (total_weight, mst_edges)
    """
    edges.sort()
    uf = UnionFind(n)
    total = 0
    mst = []

    for w, u, v in edges:
        if uf.union(u, v):
            total += w
            mst.append((u, v, w))

    return total, mst


def prim_mst(n, adj):
    """
    adj: adjacency list of (neighbor, weight)
    Returns: (total_weight, mst_edges)
    """
    visited = [False] * n
    pq = [(0, 0, -1)]  # (weight, node, parent)
    total = 0
    mst = []

    while pq:
        w, u, parent = heapq.heappop(pq)
        if visited[u]:
            continue
        visited[u] = True
        total += w
        if parent != -1:
            mst.append((parent, u, w))

        for v, w2 in adj[u]:
            if not visited[v]:
                heapq.heappush(pq, (w2, v, u))

    return total, mst


# Example graph with 5 nodes

adj = [[] for _ in range(5)]
for w, u, v in edges:
    adj[u].append((v, w))
    adj[v].append((u, w))

print("Kruskal's MST:", kruskal_mst(5, edges))
print("Prim's MST:", prim_mst(5, adj))

## Practice Problems

<ProblemCard title="Minimum Spanning Tree Weight" difficulty="medium" pattern="MST">
  Given `n` nodes and a list of edges `(u, v, weight)`, find the total weight of the minimum spanning tree.

  **Example:** `n = 5, edges = [(0,1,2),(0,3,3),(1,2,1),(1,3,4),(2,4,5),(3,4,6)]` → MST weight = 12 (edges: (1,2,1) + (0,1,2) + (0,3,3) + (2,4,5))

  **Constraints:** `1 <= n <= 10^4`, `1 <= edges.length <= 10^5`

  **Solution approach:** Apply Kruskal's (sort + union-find) or Prim's (heap). Both give the same total weight. For sparse graphs, Kruskal's is usually simpler to implement.

## Key Takeaways

<InsightBox title="Key Insights">
- Both Kruskal's and Prim's are greedy and always produce optimal MSTs — the cut property guarantees this.
- Kruskal's algorithm is often easier to implement because it works on a sorted edge list and uses Union-Find.
- Prim's algorithm is better for dense graphs (it doesn't sort all edges upfront).
- MST problems are common in network design interviews. Know both algorithms so you can choose the right tool.
</InsightBox>
