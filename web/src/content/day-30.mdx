## Capstone Problem

<ProblemCard title="Word Ladder II — Putting It All Together" difficulty="hard" pattern="Multi-Pattern">
  Given two words (`beginWord` and `endWord`) and a dictionary `wordList`, find all shortest transformation sequences from `beginWord` to `endWord`, where:
  - Only one letter can be changed per step
  - Each intermediate word must exist in `wordList`
  - `beginWord` may not be in `wordList`

  **Example:**
  ```
  beginWord = "hit", endWord = "cog"
  wordList = ["hot","dot","dog","lot","log","cog"]
  Output: [
    ["hit","hot","dot","dog","cog"],
    ["hit","hot","lot","log","cog"]
  ]
  ```

  **Constraints:** `1 <= beginWord.length <= 10`, `1 <= wordList.length <= 1000`

  **This problem integrates:**
  - **BFS** to find shortest path length (Day 11, 12)
  - **DFS / Backtracking** to reconstruct all paths (Day 22)
  - **Graph construction** implicit from word transformations (Day 10)
  - **Optimization via pruning** — stop exploring paths longer than the shortest found

  **Solution approach:** BFS from beginWord to endWord, recording distances. Then DFS/backtrack from beginWord using only neighbors with distance + 1 to reconstruct all shortest paths.
</ProblemCard>

## Code Example

<CodePlayground language="python" initialCode={`from collections import defaultdict, deque


def find_ladders(begin, end, word_list):
    """Find all shortest transformation sequences."""
    words = set(word_list)
    if end not in words:
        return []

    # Build adjacency: for each word, all words one letter away
    adj = defaultdict(list)
    for w in words | {begin}:
        for i in range(len(w)):
            for c in "abcdefghijklmnopqrstuvwxyz":
                if c == w[i]:
                    continue
                nxt = w[:i] + c + w[i + 1:]
                if nxt in words:
                    adj[w].append(nxt)

    # BFS to find shortest distances
    dist = {begin: 0}
    q = deque([begin])
    while q:
        cur = q.popleft()
        if cur == end:
            break
        for nxt in adj[cur]:
            if nxt not in dist:
                dist[nxt] = dist[cur] + 1
                q.append(nxt)

    if end not in dist:
        return []

    # DFS backtracking to reconstruct all shortest paths
    result = []

    def dfs(path):
        if path[-1] == end:
            result.append(path[:])
            return
        for nxt in adj[path[-1]]:
            if dist.get(nxt, float("inf")) == dist[path[-1]] + 1:
                path.append(nxt)
                dfs(path)
                path.pop()

    dfs([begin])
    return result


print(find_ladders("hit", "cog",
    ["hot", "dot", "dog", "lot", "log", "cog"]))
