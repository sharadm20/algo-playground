## Overview

Linked lists are the classic "pointer manipulation" data structure. Unlike arrays, linked list nodes are scattered in memory, connected by references (pointers). This makes insertion and deletion O(1) at the cost of O(n) access. The challenge in linked list problems is not the algorithm — it's correctly rewiring pointers without losing nodes.

Interview problems focus on three patterns: reversal (iterative and recursive), fast-and-slow pointer (cycle detection, middle element), and merging/partitioning. Every linked list problem becomes easy once you get comfortable drawing boxes and arrows on a whiteboard.

## Key Concepts

- **Singly vs Doubly Linked**: Singly has `next` only; doubly has `prev` and `next`. Doubly uses more memory but enables O(1) deletion of a node reference.
- **Fast & Slow Pointer**: One pointer moves 2 steps, one moves 1. Detects cycles, finds the middle, finds the start of a cycle.
- **Dummy Node**: A sentinel node before the head simplifies edge cases (empty list, single node, deletion of head).
- **Reversal**: Iteratively rewire `current.next = prev` while moving three pointers: `prev`, `current`, `next_temp`.

## Code Example

<CodePlayground language="python" initialCode={`class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def reverse_list(head):
    prev, curr = None, head
    while curr:
        next_temp = curr.next
        curr.next = prev
        prev = curr
        curr = next_temp
    return prev

def list_to_nodes(arr):
    dummy = ListNode()
    cur = dummy
    for v in arr:
        cur.next = ListNode(v)
        cur = cur.next
    return dummy.next

def nodes_to_list(head):
    res = []
    while head:
        res.append(head.val)
        head = head.next
    return res

print(nodes_to_list(reverse_list(list_to_nodes([1, 2, 3, 4, 5]))))  # [5, 4, 3, 2, 1]
`} />

## Practice Problems

<ProblemCard title="Reverse Linked List" difficulty="easy" pattern="Iterative / Recursive">
  Given the `head` of a singly linked list, reverse it and return the new head.

  **Example:** `1 → 2 → 3 → 4 → 5` → `5 → 4 → 3 → 2 → 1`

<ProblemCard title="Merge Two Sorted Lists" difficulty="easy" pattern="Two Pointers">

  **Example:** `1 → 2 → 4` + `1 → 3 → 4` → `1 → 1 → 2 → 3 → 4 → 4`
</ProblemCard>

<ProblemCard title="Linked List Cycle" difficulty="easy" pattern="Fast & Slow Pointer">

</ProblemCard>

## Key Takeaways

<InsightBox title="Key Insights">
- Drawing the pointer rewiring before coding prevents the most common bugs.
- The dummy/ sentinel node eliminates nearly all edge-case special handling.
- Fast & slow pointer is the single most versatile linked list technique — practice it until it's automatic.
</InsightBox>
