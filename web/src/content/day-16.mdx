## Overview

Binary search is the most fundamental divide-and-conquer algorithm: repeatedly halve the search space until you find the target. What makes it powerful is its versatility — it works not just on sorted arrays, but on any **monotonic function** where you can ask "is this too high?" and get a yes/no answer. This is the "search on answer space" pattern, useful for problems that ask for the minimum feasible value satisfying a constraint.

The three common variants are: classic binary search (find exact value), rotated array search (find in a shifted sorted array), and predicate binary search (find boundary where a condition flips from false to true).

## Key Concepts

- **Classic BS**: Requires a sorted array. Midpoint computed as `lo + (hi - lo) // 2` to avoid overflow. Three templates depending on whether you return the index, the insertion point, or a boundary.
- **Rotated Array**: A sorted array that has been rotated at an unknown pivot. One half is always fully sorted — check which half contains the target by comparing with the midpoint.
- **Search on Answer Space**: When the problem asks for a minimum (or maximum) value satisfying a condition, binary search over the range of possible answers and test feasibility in O(n) each iteration.
- **Off-by-One**: The hardest part of binary search. Know your invariant: `[lo, hi]` inclusive vs `[lo, hi)` exclusive determines the loop condition and update rules.

## Code Example

<CodePlayground language="python" initialCode={`def binary_search(arr: list[int], target: int) -> int:
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if arr[mid] == target:
            return mid
        if arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1


def search_rotated(nums: list[int], target: int) -> int:
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] == target:
            return mid
        if nums[lo] <= nums[mid]:
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1


print(binary_search([1, 2, 3, 4, 5], 3))  # 2
print(search_rotated([4, 5, 6, 7, 0, 1, 2], 0))  # 4

## Key Takeaways

<InsightBox title="Key Insights">
- The invariant is everything. Decide on `lo <= hi` vs `lo < hi` early and be consistent about whether `hi` is inclusive or exclusive.
- For rotated array problems, identify the sorted half by comparing `nums[lo] <= nums[mid]`. The pivot is always in the unsorted half.
- Predicate binary search is the most general form: define a function `f(x) -> bool` that is `False` for all valid answers and `True` for all invalid (or vice versa), then find the boundary.
- When binary searching on an answer space, the initial bounds matter. Start with `lo = 0` (or the minimum possible answer) and `hi = max(nums)` or the maximum feasible value.
</InsightBox>
