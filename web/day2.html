Day 2: Advanced Array Manipulation

Core Techniques Deep Dive

Current 📅 March 30, 2026 ⏱️ 4-5 hours

Topic Overview

Day 2 builds upon foundational concepts, diving deeper into advanced array manipulation techniques. These patterns form the backbone of efficient algorithm design and appear frequently in technical interviews.

Today's focus is on mastering four critical techniques that transform seemingly complex problems into elegant, efficient solutions.

Core Techniques

1. Two-Pointer Technique

The two-pointer technique uses two indices that traverse the array in coordination to solve problems in a single pass, eliminating the need for nested loops.

Pattern Description Applications
Opposite Direction Left starts at beginning, right at end, move toward each other Two Sum (sorted), palindrome checking
Same Direction Fast-slow pointers, both move left to right Remove duplicates, find middle element
Three-Way Partitioning Maintains three regions around a pivot Dutch National Flag, sort colors

2. Sliding Window Approach

Maintains a contiguous subarray (window) that slides through the array, updating the solution incrementally rather than recomputing from scratch.

Pattern Description Applications
Fixed Size Window Window size remains constant (k elements) Maximum average subarray, moving averages
Dynamic Size Window Expands and contracts based on condition Min size subarray sum, longest substring

3. Prefix Sum Method

Precomputes cumulative sums, enabling O(1) range sum queries after O(n) preprocessing.

  • Basic: prefix[i] = sum of elements from index 0 to i-1
  • Range Query: sum(i, j) = prefix[j+1] - prefix[i]
  • With Hash Map: Count subarrays with sum equals k
  • Kadane's Algorithm: Maximum subarray sum

4. Hash Map Applications

Hash maps provide O(1) average-case lookup for frequency counting, complement searches, and grouping.

  • Frequency Counting: Track occurrence count of each element
  • Complement Lookup: Store seen elements, search for target - current
  • Grouping by Key: Use transformed value as key (e.g., sorted string)

Essential Problems

Two Sum II (Input Array Sorted) Medium

Pattern: Two-Pointer (Opposite Direction)

Problem: Given sorted array and target, find two numbers adding to target.

Example: numbers = [2,7,11,15], target = 9 → [1,2]

Solution: Use converging pointers. If sum < target, move left pointer right. If sum > target, move right pointer left. O(n) time, O(1) space.

Remove Duplicates from Sorted Array Easy

Pattern: Two-Pointer (Same Direction)

Problem: Remove duplicates in-place, return new length.

Example: nums = [0,0,1,1,2] → length = 3, nums = [0,1,2,_,_]

Solution: Slow pointer tracks unique position, fast pointer scans. When different, copy to slow+1. O(n) time, O(1) space.

Maximum Subarray (Kadane's Algorithm) Medium

Pattern: Prefix Sum / Dynamic Programming

Problem: Find contiguous subarray with maximum sum.

Example: nums = [-2,1,-3,4,-1,2,1,-5,4] → 6 ([4,-1,2,1])

Solution: At each position, decide: extend previous subarray or start new. Track global maximum. O(n) time, O(1) space.

Product of Array Except Self Medium

Pattern: Prefix Products

Problem: Return array where each element is product of all other elements.

Example: nums = [1,2,3,4] → [24,12,8,6]

Solution: Compute left products, then right products. Multiply together for result. No division allowed. O(n) time, O(1) space excluding output.

Trapping Rain Water Hard

Pattern: Two-Pointer with Max Tracking

Problem: Calculate water trapped between bars after rain.

Example: height = [0,1,0,2,1,0,1,3,2,1,2,1] → 6 units

Solution: Track max from left and right. Water at position = min(left_max, right_max) - height. O(n) time, O(1) space.

Code Examples

Two Sum Sorted - Python

def two_sum_sorted(numbers, target): left, right = 0, len(numbers) - 1 while left < right: current_sum = numbers[left] + numbers[right] if current_sum == target: return [left + 1, right + 1] # 1-indexed elif current_sum < target: left += 1 else: right -= 1 return [-1, -1]

Two Sum Sorted - Rust

fn two_sum_sorted(numbers: &[i32], target: i32) -> Vec { let mut left: i32 = 0; let mut right: i32 = numbers.len() as i32 - 1; while left < right { let sum = numbers[left as usize] + numbers[right as usize]; if sum == target { return vec![left + 1, right + 1]; } else if sum < target { left += 1; } else { right -= 1; } } vec![-1, -1] }

Kadane's Algorithm - Python

def max_subarray_sum(nums): if not nums: return 0 max_current = max_global = nums[0] for i in range(1, len(nums)): max_current = max(nums[i], max_current + nums[i]) max_global = max(max_global, max_current) return max_global

Complexity Comparison

Approach Time Complexity Space Complexity
Brute Force (Nested Loops) O(n²) O(1)
Two-Pointer O(n) O(1)
Sliding Window O(n) O(1) or O(k)
Prefix Sum O(n) preprocessing, O(1) query O(n)
Hash Map O(n) average O(n)

💡 Key Insights

  • Recognize Sorted Array Problems: If input is sorted, consider two-pointer before hash map to achieve O(1) space
  • Identify Window Properties: Fixed window for size-k problems, dynamic window for optimization with constraints
  • Prefix Sum for Range Queries: Multiple range sum queries? Build prefix array for O(1) per query
  • Hash Map for Complement: Looking for pairs with specific sum? Store complements in hash map
  • Contract When Condition Violated: In sliding window, shrink from left when constraint is broken
  • Precompute for Efficiency: Prefix sums/products trade O(n) space for O(1) query time

Practice Problems (Homework)

Easy Problems

  • Best Time to Buy and Sell Stock - Track minimum price, calculate max profit
  • Maximum Average Subarray I - Fixed size sliding window
  • Find All Numbers Disappeared in an Array - Index marking or hash set
  • Valid Anagram - Character frequency counting
  • Contains Duplicate - Hash set for duplicate detection

Medium Problems

  • 3Sum - Sort + Two pointers, skip duplicates
  • Container With Most Water - Two pointers from ends
  • Subarray Sum Equals K - Prefix sum with hash map
  • Longest Repeating Character Replacement - Sliding window with frequency
  • Minimum Window Substring - Dynamic window with character counts

Hard Problems

  • Trapping Rain Water - Two pointers with max tracking
  • Minimum Window Substring - Advanced sliding window
  • First Missing Positive - Index marking technique
