🎓 Topics Covered

1. Interval Dynamic Programming

Interval DP solves problems by considering all possible subintervals. The optimal solution for [i, j] is computed by trying all split points k and combining solutions of [i, k] and [k+1, j].

Key Problems:

  • Palindrome Partitioning (Minimum Cuts) - Partition string into palindromes with minimum cuts
  • Burst Balloons - Maximize coins from bursting balloons
  • Stone Merge Problem - Min cost to merge all piles into one
  • Optimal Game Strategy - Max value Player 1 can get when both play optimally

Template:

def interval_dp(i, j): if i == j: return base_case if (i, j) in memo: return memo[(i, j)] result = infinity or -infinity for k in range(i, j): result = optimize(result, dp(i, k) + dp(k+1, j) + cost(i, j)) memo[(i, j)] = result return result

💡 Key Insight

Think: "What happens LAST in this range?" This reverse thinking is crucial for interval DP.

2. Game Theory DP

Game theory DP applies minimax algorithms to two-player zero-sum games. The maximizer tries to maximize the score, while the minimizer tries to minimize it.

Key Problems:

  • Minimax Algorithm - Two-player zero-sum games
  • Nim Game Variants - Losing positions are multiples of (max_removal + 1)
  • Coin Game (Pick from Ends) - Players alternately pick from either end
Nim Pattern: Losing position if n % (max_removal + 1) == 0
Coin Game: dp[i][j] = max(coins[i] + min(dp[i+2][j], dp[i+1][j-1]),
                    coins[j] + min(dp[i+1][j-1], dp[i][j-2]))

💡 Key Insight

Assume opponent plays optimally too. Your gain is their loss in zero-sum games.

3. Probability Dynamic Programming

Probability DP computes expected values by averaging over all possible outcomes, weighted by their probabilities.

Key Problems:

  • Expected Values - E[X] = Σ (value × probability)
  • Random Walks - Expected steps to reach target: E = n²
  • Dice Problems - Expected rolls for specific face: E = 1/p = 6
  • Coupon Collector - E = n × H(n) ≈ n × ln(n)
Coupon Collector: E = n × (1 + 1/2 + 1/3 + ... + 1/n)

💡 Key Insight

Work backwards from terminal states, or use linearity of expectation when possible.

4. Advanced Patterns

Specialized DP techniques used in competitive programming and advanced algorithm design.

Techniques:

  • Plug DP - Track connectivity on grid boundaries (Hamiltonian paths, domino tilings)
  • Broken Profile DP - Process cell by cell, maintain boundary state
  • Bitmask + Connectivity - Combine visited set with connectivity info

💡 When to Use

These are advanced techniques for grid problems, path counting, and connectivity constraints.

📖 Summary

Interval DP

  • Think: "What happens LAST in this range?"
  • Classic problems: palindrome partitioning, burst balloons, stone merge
  • Time: typically O(n³), Space: O(n²)

Game Theory DP

  • Minimax: maximizer vs minimizer
  • Optimal strategies assume opponent also plays optimally
  • Nim: losing positions are multiples of (max_move + 1)

Probability DP

  • Expected values: E[X] = Σ(value × probability)
  • Work backwards from terminal states
  • Coupon collector: E = n × H(n) ≈ n × ln(n)

Advanced Patterns

  • Plug DP: track connectivity on grid boundaries
  • Broken Profile: process cell by cell, maintain boundary state
  • These are competitive programming techniques
