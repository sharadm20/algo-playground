Pattern 1: Arrays & Hash Map Patterns (Days 1-2)

1.1 Two Sum - Complement Lookup

The classic Two Sum problem demonstrates the power of hash maps for complement lookup. Instead of checking all pairs (O(n²)), we can find the complement in O(1) using a hash map. 

def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []

# Time: O(n), Space: O(n)

1.2 3Sum - Sort + Two-Pointer

Extending Two Sum to triplets requires sorting and the two-pointer technique. Key insight: skip duplicates to avoid redundant triplets. 

def three_sum(nums):
    nums.sort()
    result = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue  # Skip duplicates
        left, right = i + 1, len(nums) - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total < 0:
                left += 1
            elif total > 0:
                right -= 1
            else:
                result.append([nums[i], nums[left], nums[right]])
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1
                left += 1
                right -= 1
    return result

1.3 Container With Most Water - Greedy Two-Pointer

Start with the widest container (both ends) and greedily move the shorter pointer inward. The greedy choice works because moving the taller pointer can only decrease the area. 

def container_with_most_water(height):
    left, right = 0, len(height) - 1
    max_area = 0
    while left < right:
        h = min(height[left], height[right])
        w = right - left
        max_area = max(max_area, h * w)
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1
    return max_area

Pattern 2: String Manipulation (Day 3)

2.1 Longest Substring Without Repeating - Sliding Window

Use a sliding window with a hash set to track characters. Expand the right pointer, and shrink from the left when a duplicate is found. 

def longest_substring_without_repeating(s):
    seen = set()
    left = 0
    max_len = 0
    for right in range(len(s)):
        while s[right] in seen:
            seen.remove(s[left])
            left += 1
        seen.add(s[right])
        max_len = max(max_len, right - left + 1)
    return max_len

# Time: O(n), Space: O(min(n, m))

2.2 Longest Palindromic Substring - Expand Around Center

Each character (and gap) can be the center of a palindrome. Expand outward and track the longest. 

def expand_around_center(s, left, right):
    while left >= 0 and right < len(s) and s[left] == s[right]:
        left -= 1
        right += 1
    return left + 1, right - 1

def longest_palindromic_substring(s):
    start, end = 0, 0
    for i in range(len(s)):
        l1, r1 = expand_around_center(s, i, i)      # Odd
        l2, r2 = expand_around_center(s, i, i + 1)  # Even
        if r1 - l1 > end - start:
            start, end = l1, r1
        if r2 - l2 > end - start:
            start, end = l2, r2
    return s[start:end + 1]

Pattern 3: Stack & Queue Applications (Day 4)

3.1 Min Stack - Two Stacks

Maintain a parallel min_stack that tracks minimum values. Push to min_stack when value is smaller than or equal to current min. 

class MinStack:
    def __init__(self):
        self.stack = []
        self.min_stack = []
    
    def push(self, val):
        self.stack.append(val)
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)

3.2 Evaluate RPN - Stack-Based Evaluation

3.3 Daily Temperatures - Monotonic Stack

Maintain a decreasing stack of indices. When current temperature is warmer than stack top, we found the next warmer day for all elements in the stack. 

def daily_temperatures(temperatures):
    result = [0] * len(temperatures)
    stack = []  # Store indices
    for i in range(len(temperatures)):
        while stack and temperatures[i] > temperatures[stack[-1]]:
            idx = stack.pop()
            result[idx] = i - idx
        stack.append(i)
    return result

Pattern 4: Linked List Patterns (Day 5)

4.1 Merge Two Sorted Lists - Dummy Node

Use a dummy node to simplify edge cases. Compare and link the smaller node. 

def merge_two_lists(list1, list2):
    dummy = ListNode()
    curr = dummy
    while list1 and list2:
        if list1.val < list2.val:
            curr.next = list1
            list1 = list1.next
        else:
            curr.next = list2
            list2 = list2.next
        curr = curr.next
    curr.next = list1 if list1 else list2
    return dummy.next

4.2 Reverse Linked List - Three-Pointer

Use prev, curr, and next_temp pointers to reverse links iteratively. 

def reverse_list(head):
    prev = None
    curr = head
    while curr:
        next_temp = curr.next
        curr.next = prev
        prev = curr
        curr = next_temp
    return prev

Pattern 5: Tree Patterns (Day 6)

5.1 Level-Order Traversal - BFS

Use a queue to process nodes level by level. Track level size to know when level ends. 

from collections import deque

def level_order(root):
    if not root:
        return []
    result = []
    queue = deque([root])
    while queue:
        level_size = len(queue)
        current_level = []
        for _ in range(level_size):
            node = queue.popleft()
            current_level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(current_level)
    return result

5.2 Validate BST - Range Validation

Pass down valid ranges (low, high) to ensure BST property globally, not just locally. 

def is_valid_bst(root, low=-∞, high=∞):
    if not root:
        return True
    if root.val <= low or root.val >= high:
        return False
    return (is_valid_bst(root.left, low, root.val) and
            is_valid_bst(root.right, root.val, high))

5.3 Diameter of Binary Tree - Height + Diameter

The longest path through any node is left_height + right_height. Track both simultaneously. 

def diameter_of_binary_tree(root):
    diameter = [0]
    def height(node):
        if not node:
            return 0
        left_h = height(node.left)
        right_h = height(node.right)
        diameter[0] = max(diameter[0], left_h + right_h)
        return 1 + max(left_h, right_h)
    height(root)
    return diameter[0]

Key Takeaways

  • Hash maps excel at frequency counting and complement lookup (O(1) lookup)
  • Two-pointer techniques work on sorted arrays or with specific constraints
  • Sliding window requires monotonic property or hash map tracking
  • Stack is LIFO (valid parentheses, expression evaluation, monotonic patterns)
  • Queue is FIFO (BFS, level-order traversal, shortest path)
  • Fast-slow pointers detect cycles and find middle elements (O(1) space)
  • Dummy nodes simplify linked list edge cases
  • Tree traversals: in-order (BST sorted), pre-order (copy), post-order (delete)
  • BFS for shortest path/level-order, DFS for exploring all paths
  • Always handle edge cases: empty input, single element, all same elements
  • Analyze time/space complexity before coding—aim for optimal solution
