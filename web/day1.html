Day 1: Arrays & Hashing

Foundation of Data Structures

Completed 📅 March 29, 2026 ⏱️ 4-5 hours

Topic Overview

Arrays and hashing form the foundation of data structures. Arrays provide contiguous memory allocation with O(1) random access, while hash tables enable average O(1) lookup operations through hash functions.

Understanding these structures is crucial because they appear in nearly every coding interview and form the basis for more complex data structures.

Key Concepts

1. Arrays

  • Contiguous memory: Elements stored in adjacent memory locations
  • O(1) access: Direct indexing for constant-time retrieval
  • Fixed size: Size determined at creation (in most languages)
  • Cache friendly: Sequential access patterns benefit from CPU caching

2. Hash Tables

  • Key-value mapping: Store data as key-value pairs
  • Hash function: Converts keys to array indices
  • Collision handling: Chaining or open addressing
  • Load factor: Ratio of elements to buckets affects performance

3. Common Patterns

  • Frequency counting: Track occurrences of elements
  • Complement lookup: Find pairs that sum to target
  • Duplicate detection: Use hash sets for O(1) existence checks

Essential Problems

Two Sum Easy

Pattern: Hash Map - Complement Lookup

Problem: Given an array and target, find two numbers that add up to target.

Example: nums = [2,7,11,15], target = 9 → [0,1]

Solution: Use a hash map to store seen numbers. For each number, check if (target - current) exists in the map. This achieves O(n) time with O(n) space.

Valid Anagram Easy

Pattern: Hash Map - Frequency Counting

Problem: Determine if two strings are anagrams of each other.

Example: s = "anagram", t = "nagaram" → true

Solution: Count character frequencies in both strings. If frequency maps match, strings are anagrams. O(n) time, O(1) space (26 lowercase letters).

Contains Duplicate Easy

Pattern: Hash Set - Existence Check

Problem: Check if array contains any duplicates.

Example: nums = [1,2,3,1] → true

Solution: Add elements to a hash set. If an element already exists in the set, return true. O(n) time, O(n) space.

Group Anagrams Medium

Pattern: Hash Map - Grouping by Key

Problem: Group anagrams together from an array of strings.

Example: ["eat","tea","tan","ate","nat","bat"] → [["eat","tea","ate"],["tan","nat"],["bat"]]

Solution: Use sorted string as key. Anagrams produce the same sorted string. Group strings by their sorted key. O(n*k log k) time where k is max string length.

Code Examples

Two Sum - Python Implementation

def two_sum(nums, target): seen = {} # value -> index for i, num in enumerate(nums): complement = target - num if complement in seen: return [seen[complement], i] seen[num] = i return [-1, -1]

Two Sum - Rust Implementation

fn two_sum(nums: &[i32], target: i32) -> Vec { use std::collections::HashMap; let mut seen: HashMap = HashMap::new(); for (i, &num) in nums.iter().enumerate() { let complement = target - num; if let Some(&idx) = seen.get(&complement) { return vec![idx as i32, i as i32]; } seen.insert(num, i); } vec![-1, -1] }

💡 Key Insights

  • Hash tables trade space for time efficiency - O(n) space for O(1) lookup
  • Use hash maps for complement problems (Two Sum pattern)
  • Use hash sets for existence checks and duplicate detection
  • Frequency counting solves anagram and grouping problems
  • Consider edge cases: empty input, single element, all same values
